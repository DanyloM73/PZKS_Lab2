# Лабораторна робота №2 з дисципліни «Програмне забезпечення комп’ютерних систем»

Консольна програма мовою Kotlin, що виконує автоматичне розпаралелювання арифметичних виразів. Вона перевіряє вираз лексичним і синтаксичним аналізатором із лабораторної роботи №1, виявляє недопустимі операції, спрощує вираз і будує дерево паралельної форми мінімальної висоти та максимальної ширини.

## Системні вимоги

- 64-бітна операційна система Windows, macOS або Linux;
- Java 21 або новіша версія;

## Завантаження

1. Відкрийте [останній реліз програми](https://github.com/DanyloM73/PZKS_Lab2/releases/latest).
2. У розділі **Assets** завантажте файл `PZKS_Lab2-1.0.0.zip` та розпакуйте його.
3. Виконайте інструкцію для своєї операційної системи.

## Встановлення та запуск у Windows

Відкрийте PowerShell і запустіть програму:

```powershell
& "$HOME\Downloads\PZKS_Lab2-1.0.0\bin\PZKS_Lab2.bat"
```

Якщо програма знаходиться в іншій папці, замініть шлях у команді на фактичний.

## Встановлення та запуск у macOS і Linux

Відкрийте термінал і перейдіть до папки програми:

```bash
cd ~/Downloads/PZKS_Lab2-1.0.0
```

Надайте файлу дозвіл на виконання (якщо потрібно):

```bash
chmod +x bin/PZKS_Lab2
```

Запустіть програму:

```bash
./bin/PZKS_Lab2
```

## Використання

Після запуску введіть арифметичний вираз і натисніть Enter:

```text
a+b*c + k - x - d - e - f/g/h/q
```

Для коректного виразу програма виводить:

- покрокову оптимізацію з переліком застосованих перетворень;
- паралельну форму виразу;
- кількість операцій, ярусів і найбільшу кількість одночасних операцій до та після оптимізації;
- дерево паралельної форми у вигляді таблиці за ярусами;
- розклад виконання операцій за ярусами.

Якщо вираз містить лексичні чи синтаксичні помилки, ділення на нуль або недопустимі аргументи функцій, програма показує тип і точне місце кожної помилки у введеному виразі.

Програма підтримує:

- числа та змінні;
- оператори `+`, `-`, `*`, `/`;
- унарні оператори `+` і `-`;
- круглі дужки;
- функції `sin`, `cos`, `tan`, `ctg`, `sqrt`, `abs`, `round`, `ln`, `log10`, `pow`, `min` і `max`.

Додаткові команди:

- `:functions` — показати перелік доступних функцій;
- `:exit` — завершити роботу програми.
